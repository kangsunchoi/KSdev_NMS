# Aegis OT NMS 장비 아이콘 표준

토폴로지, 장비 목록, 이벤트 상세에서 같은 장비에 아이콘을 표시할 때는 동일한 장비 유형과 원본 도안을 사용한다. 신규 시안과 구현 검수에도 이 기준을 적용한다.

- 파일명 `Unmaintained-Design-Icons_v1.0.pptx`
- 표지명 `Cisco Reference Design Icon Library`
- 표지 표기 `AS-IS ONLY`, 마지막 추가일 2015-07-15
- 원본 SHA-256 `527686380994529FBF0E11186989D6DC408AC66F2F8F47FB3E3C1BA095B80C64`

## 장비 유형 대응

| 수집 정보로 확인한 유형 | 원본 도안 | 슬라이드 |
|---|---|---|
| 라우터 | Router | 2 |
| L2 스위치 | Layer 2 Switch | 2 |
| L3 스위치 | Layer 3 Switch | 2 |
| L2/L3 구분이 없는 일반 스위치 | Workgroup Switch | 2 |
| 엔지니어링 워크스테이션 | Workstation | 2 |
| 서버 | Server | 4 |
| 저장장치 | Storage | 4 |
| 무선 AP | Wireless Access Point | 4 |
| 무선 컨트롤러 | Wireless LAN Controller | 4 |

장비명이나 연결 위치만으로 모델과 계층을 추정하지 않는다. PLC, HMI, 원격 I/O, 드라이브처럼 전용 도안의 대응이 확인되지 않은 유형은 유형명을 유지하고 별도 매핑 대상으로 기록한다. 논리 자산, 미관리 구간과 사이트 그룹은 물리 장비와 구별한다.

## 화면 적용

원본의 비율과 세부 형태를 유지하며, 원본이 제공하는 저채도 변형이 있는 경우 흰 바탕에서 우선 사용한다. 링크는 기본 검정, 주의 주황, 단절 빨강, 선택 파랑으로 표현한다. 장애와 선택 상태는 라벨이나 윤곽선으로도 구별한다. 장비 사이 케이블에는 가상의 분기점을 추가하지 않는다.

검수 시 같은 장비를 토폴로지와 상세 화면에서 대조하고, 축소 상태에서도 유형명과 상태를 읽을 수 있는지 확인한다. 이 문서는 도안 선택 기준이며 개별 도안의 적용 여부는 구현 변경에서 확인한다.
